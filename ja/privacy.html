プライバシー

Thermocline は 616 Labs, LLC（インディアナ州インディアナポリス）が制作しています。本ポリシーは、iPhone、iPad、Mac、Apple Watch 用の Thermocline に適用されます。最終更新日：2026年11月22日。

要点：Thermocline はあなたのデータを収集しません。アカウントも、広告も、分析も、トラッキングもなく、開発者はサーバーを運営していません。ログブックはあなたのデバイスに、また同期をオンにした場合はあなた自身の iCloud にとどまります。

ログブックの保管場所

ダイブ、ポイント、器材、バディ、カード、写真はあなたのデバイスに保存されます。「iCloud と同期」をオンにすると、あなた自身の Apple Account のプライベート iCloud データベースにも保存され、あなたのほかのデバイスからも見られるようになります。そのデータはApple のプライバシーポリシーに基づいて Apple が保管し、開発者はそれを読むことができません。

ログブック全体はいつでも書き出せます（UDDF、CSV、MacDive XML）。また、アプリを削除すると、そのデバイス上のコピーは削除されます。iCloud 上のコピーを削除するには、同期をオフにしてから、デバイスの iCloud 設定でこのアプリのデータを削除してください。

アプリが求めるアクセス許可

どの許可も、その機能を使うときにだけ求められます。許可しなくても、アプリのほかの部分は引き続き使えます。

アクセス許可用途
Bluetoothダイブコンピューターからダイブをダウンロードするため。
USB とシリアルデバイス（Mac）ケーブルで接続したコンピューターからダイブをダウンロードするため。
位置情報あなたが指示したときに、ダイブポイントの位置をマークするため。Apple Watch では、水面でポイントをマークするため。
写真ダイブの写真を追加するため。また、iCloud写真 をオンにしている場合は写真をそこにリンクするため。
カメラあなたが指示したときに、Cカードをスキャンするため。
連絡先あなたが指示したときに、バディをその人の連絡先にリンクするため。

これらの機能が読み取った内容は、あなたのデバイス上のログブックと、あなたの iCloud の中にとどまります。開発者には送信されません。

Apple のサービス

地図、場所の検索、場所の名前は Appleマップ から提供されます。地図を表示したり、場所を検索したり、位置に名前を付けたりすると、Apple はApple のプライバシーポリシーに基づいてそのリクエストを受け取ります。内蔵の 76,000+ か所のダイブポイントと沈船は、ネットワークに接続せずにデバイス上で検索されます。

追加したリンク

ダイブに YouTube や Vimeo のリンクを追加すると、Thermocline はそのリンクを保存します。リンクは、あなたがタップしたときにだけブラウザで開きます。

ベータ版

ベータ版は Apple の TestFlight で配信されます。Apple の TestFlight の規約に記載されているとおり、Apple は、あなたが送信を選んだクラッシュレポートとフィードバック、およびデバイスとビルドに関する基本的な情報を、開発者と共有する場合があります。これらの情報は、Thermocline の修正と改善のためにのみ使用されます。

このウェブサイト

このセクションはウェブサイトのみに関するものです。前述のとおり、アプリには分析機能はありません。

thermoclineapp.com は、訪問数を数えるために Cloudflare Web Analytics を使用しています。数える内容は、読まれたページ、訪問者を送ったサイト、デバイスの種類です。Cookie は設定せず、ほかのサイトをまたいであなたを追跡することも、あなたのプロフィールを作成することもありません。このウェブサイトには広告もほかの分析もありません。サイトは GitHub Pages でホストされており、サイトを配信する GitHub と Cloudflare は、セキュリティのために標準的なサーバーログ（IP アドレスなど）を保持する場合があります。

子ども

Thermocline は子どもを対象としたものではなく、誰の個人情報も、それと知りながら収集することはありません。

変更

本ポリシーが変更された場合は、新しい日付を付けた新しい版をここに掲載します。変更によって、あなた自身のログブックに対するあなたの管理が減ることはありません。
