Thermocline
가이드 문제 해결 개인정보 보호 베타 참여하기

지원

iPhone, iPad, Mac, Apple Watch용 Thermocline 베타 도움말. Thermocline은 Apple 기기 전용입니다.

문제나 아이디어 보고

가장 빠른 방법: 앱에서 스크린샷을 찍은 다음 TestFlight의 베타 피드백 공유로 보내세요. 빌드와 기기 정보가 첨부되어 개발자에게 전달되므로 훨씬 빨리 고칠 수 있습니다.

brian@616labs.net으로 이메일을 보내셔도 됩니다. 기기, 빌드 번호(TestFlight에 표시됨), 기대한 결과를 함께 알려 주세요.

어떻게 하나요…? 가이드는 모든 작업을 단계별로 다루고, 문제 해결은 연결, 동기화, 가져오기, 사진 문제를 다룹니다.

시작하기

  • 둘러보기를 하세요. 프로필 → 도움말 → 둘러보기 보기는 내 로그북이 아닌 샘플 로그북으로 모든 화면을 안내합니다.
  • 로그북을 가져오세요. 프로필 → 내 데이터 → 로그북 파일 가져오기. MacDive(XML 또는 UDDF), Shearwater Cloud 데이터베이스, UDDF, CSV를 읽습니다. 추가할 다이빙은 직접 선택하며, 읽을 수 없는 항목은 목록으로 보여 줍니다.
  • 다이브 컴퓨터에서 다운로드하세요. iPhone: 로그북 → 다이빙 다운로드. Mac: 파일 → 다이브 컴퓨터에서 다운로드…, Bluetooth 또는 USB 케이블로. Bluetooth로 Shearwater Perdix 및 Perdix 2에서 테스트했습니다.

케이블 다운로드 테스트 (Mac)

USB 및 시리얼 케이블 다운로드는 많은 다이브 컴퓨터용으로 만들었지만 아직 실제 하드웨어에서 시도해 보지 않았으므로, 모든 시도가 도움이 됩니다.

  • 파일 → 다이브 컴퓨터에서 다운로드…를 선택한 다음 USB 케이블, 다이브 컴퓨터 모델, 포트를 선택하세요.
  • Shearwater Predator나 초기 Petrel(Petrel 1)은 먼저 시스템 설정 → Bluetooth에서 페어링하세요. 그러면 목록에 해당 포트가 나타날 수 있습니다.
  • 성공하든 실패하든 다운로드 로그…를 열고 로그 저장…을 선택한 다음, 베타 피드백 공유나 이메일로 파일을 보내 주세요.

자주 묻는 질문

다이브 컴퓨터가 연결되지 않습니다. Shearwater 컴퓨터는 마지막으로 페어링한 기기를 기억합니다. 페어링된 휴대폰이나 다른 앱이 근처에 있으면 컴퓨터가 그쪽에 대신 연결될 수 있습니다. 다른 다이빙 앱을 닫고, Bluetooth를 껐다가 켠 다음, 컴퓨터를 Bluetooth 업로드 모드로 두고 다시 시도하세요.

동기화 후 다이빙이 사라지거나 중복되었습니다. 아무것도 바꾸기 전에 프로필 → 동기화의 스크린샷을 찍어 보내 주세요. 프로필 → 내 데이터 → 복원 지점으로 로그북을 가져오기나 병합 이전으로 되돌릴 수 있습니다.

Mac과 iPhone이 일치하지 않습니다. 모든 기기에서 TestFlight로 Thermocline을 최신 빌드로 업데이트하세요. 이전 빌드는 업데이트할 때까지 변경 사항 전송을 멈추고, 그렇다고 알려 줍니다. 잃는 것은 없습니다.

SAC 수치가 이상해 보입니다. 옆에 있는 계산 방법을 탭하면 사용한 모든 입력값을 볼 수 있습니다: 각 탱크, 내용적, 가스, 압력, 온도. 그래도 이상해 보이면 그 화면의 스크린샷을 보내 주세요.

다른 앱으로 옮기기. 프로필 → 내 데이터 → 내보내기로 로그북 전체를 UDDF, CSV 또는 MacDive XML로 저장합니다.

안전

Thermocline은 로그북입니다. 다이브 컴퓨터가 기록한 것을 보여 주며, 감압은 절대 계산하지 않습니다. 사이트 위치는 기록용이며, 내비게이션용이 아닙니다.

개인정보 보호

계정, 분석, 개발자 서버가 없습니다. 개인정보 처리방침을 참고하세요.

Thermocline, 다이빙 로그북. 다이빙 계획이나 내비게이션용이 아닙니다.
