隐私

Thermocline 由位于印第安纳州印第安纳波利斯的 616 Labs, LLC 制作。本政策适用于 iPhone、iPad、Mac 和 Apple Watch 版 Thermocline。最后更新：2026年11月22日。

简而言之：Thermocline 不收集你的数据。没有账户、没有广告、没有分析、没有跟踪，开发者也不运行任何服务器。你的潜水日志保留在你的设备上；如果你打开同步，也会保留在你自己的 iCloud 中。

你的潜水日志存放在哪里

你的潜水、潜点、装备、潜伴、卡片和照片存储在你的设备上。如果你打开“与 iCloud 同步”，它们还会存储在你自己的 Apple账户的私有 iCloud 数据库中，以便你的其他设备可以看到。Apple 根据Apple 的隐私政策保管这些数据，开发者无法读取。

你可以随时导出整个潜水日志（UDDF、CSV 或 MacDive XML），删除 App 会移除该设备上的副本。要移除 iCloud 副本，请关闭同步，并在设备的 iCloud 设置中删除该 App 的数据。

App 请求的权限

每项权限仅在你使用相应功能时才会请求，你可以拒绝，并继续使用 App 的其余部分。

权限用途
蓝牙从你的潜水电脑下载潜水。
USB 和串行设备（Mac）从通过数据线连接的电脑下载潜水。
位置在你要求时标记潜点的位置。在 Apple Watch 上，在水面标记潜点。
照片添加潜水照片，并在你打开“iCloud照片”时将照片与其关联。
相机在你要求时扫描你的潜水证书卡。
联系人在你要求时将潜伴与其联系人关联。

这些功能读取的内容保留在你设备上的潜水日志和你的 iCloud 中，不会发送给开发者。

来自 Apple 的服务

地图、地点搜索和地点名称来自 Apple地图。当你查看地图、搜索地点或为位置命名时，Apple 会根据Apple 的隐私政策收到该请求。内置的 76,000+ 个潜点和沉船在你的设备上搜索，无需网络连接。

你添加的链接

如果你为潜水添加 YouTube 或 Vimeo 链接，Thermocline 会存储该链接。只有在你轻点它时，它才会在浏览器中打开。

测试版

测试版通过 Apple 的 TestFlight 提供。按照 Apple 的 TestFlight 条款所述，Apple 可能会与开发者共享你选择发送的崩溃报告和反馈，以及有关你的设备和构建版本的基本信息。这些信息仅用于修复和改进 Thermocline。

本网站

本节仅涉及网站；如上所述，App 没有分析功能。

thermoclineapp.com 使用 Cloudflare Web Analytics 统计访问量：阅读了哪些页面、哪个网站将访问者引来，以及设备类型。它不设置 Cookie，不会在其他网站上跟踪你，也不会建立你的个人资料。本网站没有广告，也没有其他分析。网站托管在 GitHub Pages 上，提供网站服务的 GitHub 和 Cloudflare 可能会出于安全目的保留标准服务器日志（例如 IP 地址）。

儿童

Thermocline 并非面向儿童，也不会在知情的情况下收集任何人的个人信息。

变更

如果本政策发生变更，新版本将连同新的日期发布在此处。变更不会减少你对自己潜水日志的控制。
