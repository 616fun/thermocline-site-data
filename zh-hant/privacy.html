隱私權

Thermocline 由位於印第安納州印第安納波利斯的 616 Labs, LLC 製作。本政策適用於 iPhone、iPad、Mac 和 Apple Watch 版 Thermocline。最後更新：2026年11月22日。

簡而言之：Thermocline 不會收集你的資料。沒有帳號、沒有廣告、沒有分析，也沒有追蹤，開發者也不經營任何伺服器。你的潛水日誌會留在你的裝置上；若你開啟同步，也會留在你自己的 iCloud 中。

你的潛水日誌存放在哪裡

你的潛水、潛點、裝備、潛伴、卡片和照片都儲存在你的裝置上。若你開啟「與 iCloud 同步」，它們也會儲存在你自己的 Apple帳號的私人 iCloud 資料庫中，讓你的其他裝置也能看到。Apple 會依據Apple 的隱私權政策保管這些資料，開發者無法讀取。

你可以隨時輸出整個潛水日誌（UDDF、CSV 或 MacDive XML），刪除 App 會移除該裝置上的副本。若要移除 iCloud 副本，請關閉同步，並在裝置的 iCloud 設定中刪除此 App 的資料。

App 要求的權限

每項權限只會在你使用相應功能時要求，你可以拒絕，並繼續使用 App 的其他部分。

權限用途
藍牙從你的潛水電腦下載潛水。
USB 和序列埠裝置（Mac）從以傳輸線連接的潛水電腦下載潛水。
位置在你要求時標記潛點的位置。在 Apple Watch 上，於水面標記潛點。
照片加入潛水照片，並在你開啟「iCloud照片」時將照片與其連結。
相機在你要求時掃描你的潛水證照卡。
聯絡人在你要求時將潛伴連結至其聯絡人。

這些功能讀取的內容會留在你裝置上的潛水日誌和你的 iCloud 中，不會傳送給開發者。

來自 Apple 的服務

地圖、地點搜尋和地點名稱來自 Apple地圖。當你檢視地圖、搜尋地點或為位置命名時，Apple 會依據Apple 的隱私權政策收到該要求。內建的 76,000+ 個潛點和沉船會在你的裝置上搜尋，不需要網路連線。

你加入的連結

若你為潛水加入 YouTube 或 Vimeo 連結，Thermocline 會儲存該連結。只有在你點一下時，連結才會在瀏覽器中打開。

測試版

測試版透過 Apple 的 TestFlight 提供。依 Apple 的 TestFlight 條款所述，Apple 可能會與開發者分享你選擇傳送的當機報告和意見回饋，以及關於你的裝置和建置版本的基本資訊。這些資訊僅用於修正和改善 Thermocline。

本網站

本節僅與網站有關；如上所述，App 沒有分析功能。

thermoclineapp.com 使用 Cloudflare Web Analytics 計算造訪次數：閱讀了哪些頁面、哪個網站將訪客引導過來，以及裝置類型。它不設定 Cookie，不會在其他網站上追蹤你，也不會建立你的個人檔案。本網站沒有廣告，也沒有其他分析。網站託管於 GitHub Pages，提供網站服務的 GitHub 和 Cloudflare 可能會基於安全目的保留標準伺服器記錄（例如 IP 位址）。

兒童

Thermocline 並非以兒童為對象，也不會在知情的情況下蒐集任何人的個人資料。

變更

若本政策有所變更，新版本將連同新的日期張貼於此。變更不會減少你對自己潛水日誌的控制。
